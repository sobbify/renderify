# PROJECT RECORD

anti-gravity is a sobmachine-maintained static spatial viewer and reconstruction pipeline. The release artifact is the repository plus its sample bundles, QA records, and build instructions.

The implementation is intentionally split into capture, pipeline, packaging, and viewer layers. That makes it possible to review the measurements independently from the visual interface.
