# REAL EXAMPLE DATA

The demo uses the real indoor apartment scene from Nerfstudio’s documented EyefulTower dataset. The checked-in viewer bundle is `web/public/artifacts/eyefultower-apartment/`.

`cloud.ply` is sampled directly from EyefulTower’s captured apartment mesh. `apartment-frame.jpg` is a real 1K photograph from the same scene. The original high-resolution dataset is not vendored into this repository; the source bundle is large and can be retrieved from the official AWS source used by Nerfstudio.

Reference: <https://docs.nerf.studio/quickstart/existing_dataset.html>.
Source project: <https://github.com/facebookresearch/EyefulTower>.
