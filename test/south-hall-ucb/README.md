# UC BERKELEY SOUTH HALL / TARGET BUNDLE

This is the reserved capture name for the UC Berkeley South Hall dataset used by anti-gravity. The current repository does not include a South Hall scan, walkthrough, navigation grid, or downloadable database artifact.

When the authorized source bundle is available, place its reconstruction output under `web/` with at least `nav.json`; optional files are `cloud.ply`, `splat.splat`, `meta.json`, and the occupancy grid. Then copy it to `web/public/artifacts/south-hall-ucb/` and open the viewer with `?capture=south-hall-ucb`.

The public references currently verified are the UC Berkeley School of Information’s South Hall page and a SketchUp Warehouse model. Neither is a ready-to-run anti-gravity navigation bundle, so no synthetic geometry is substituted here.
